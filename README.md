# Cost Decoded

Automated faceless Shorts channel: how companies really make money, and how they get more of yours.

- `RUNBOOK.md`: the production playbook (topics, script rules, locked editing formula, publishing routes).
- `engine.py` (+ `engine_v2.py` helpers): renders a JSON script into a finished Short.
- `photos.py`: finds openly licensed photos and makes cutouts.
- `shorts/`: scripts. `media/`: rendered videos served to Metricool.
- `setup.sh`: installs the voice engine and models in a fresh session.
