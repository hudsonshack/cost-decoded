Cost Decoded Uploader

Privacy Policy and Terms of Use · Operated by Hudson Shack · Last updated November 6, 2026

What this app is

Cost Decoded Uploader is a private, internal tool used only by Hudson Shack to upload, schedule and review analytics for videos on the Cost Decoded YouTube channel, which Hudson Shack owns. It is not offered to the public and no other users can sign in to it.

YouTube API Services

This app uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

Data the app accesses

  • Upload access to the Cost Decoded channel, used only to upload and schedule that channel's own videos.
  • Read-only access to that channel's YouTube Analytics (views, watch time, subscribers gained), used only to decide what videos to make next.
  • Basic channel information needed to identify the channel.

How data is used, stored and shared

  • Data is used only to run the Cost Decoded channel. It is never sold, shared with third parties or used for advertising.
  • Analytics summaries may be saved in Hudson Shack's private project files for planning. Raw API data is not kept longer than 30 days unless it has been refreshed.
  • The sign-in token is stored privately and is used only by this tool.

Revoking access

Access can be revoked at any time from the Google security settings page: security.google.com/settings/security/permissions. Revoking access stops the app from working and any stored data is deleted within 30 days.

Cookies

This app does not place cookies or tracking technologies on any device.

Terms of use

The app is provided as-is for Hudson Shack's own use. Uploaded content must follow YouTube's Community Guidelines and monetization policies.
